# Telugu + English Offline Bible

Prepared from the two supplied WordProject ZIP archives:
- `kj_new.zip` — English KJV
- `tel_new.zip` — Telugu Bible

Included data:
- 66 books
- 1,189 chapters
- 31,102 verses
- Telugu + English verse pairs
- Offline JSON database
- Flutter reader source with book/chapter selection, Telugu/English toggle, search, bookmarks, sharing, font size, and system dark mode.

The supplied Telugu and English files were parsed and their verse-number sets were checked chapter-by-chapter; no verse-count mismatches were found.

This package is source/data, not a compiled APK. A Flutter SDK/build environment is required to build the APK.
